# Guess the Number Game

A simple command-line guessing game built with **Rust**.

## How to Play

- The computer generates a random number between 1 and 100.
- Enter your guess in the terminal.
- The game tells you whether your guess is too small or too large.
- Guess the correct number to win!

## Run the Game

Clone the repository:

```bash
git clone https://github.com/dewdropx/guessing-game.git
cd guessing-game
```

Run the game:

```bash
cargo run
```
